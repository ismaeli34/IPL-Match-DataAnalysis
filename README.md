# IPL-Match-DataAnalysis
🏏 IPL 2022 Match Data Analysis
📌 Project Overview
The Indian Premier League (IPL) is a major professional T20 cricket league. This project explores the match-level data from the 2022 IPL season. The goal is to use data science to understand what determines a match outcome, how specific players performed, and the overall dynamics of the teams throughout the tournament.

📊 Key Insights & Features
The project analyzes several important aspects of the game, including:

Team Performance: Tracking which teams won the most matches (e.g., Gujarat and Rajasthan).

Match Conditions: Examining how the toss decision (batting or fielding first) and the venue influenced the final result.

Player Statistics: Identifying top scorers and best individual bowling performances across the 74 matches in the dataset.

Winning Margins: Analyzing how dominant teams were by looking at victory margins in terms of runs and wickets.

🛠️ Data & Tools
Dataset: Includes 74 match entries with 20 detailed columns such as venues, toss winners, scores, and "Player of the Match" awards.

Python Libraries:

Pandas & NumPy: For data cleaning and numerical operations.

Seaborn & Matplotlib: For creating clear statistical visualizations and charts.

🚀 How to Use
Prerequisites: Ensure you have Python installed along with the libraries listed above.

Run the Notebook: Open IPL_Capstone_Project.ipynb in any Jupyter environment (like JupyterLab or VS Code).

Data File: Make sure the IPL.csv file is in the same folder as the notebook to allow the data to load correctly.
